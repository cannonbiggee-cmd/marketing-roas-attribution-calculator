# marketing-roas-attribution-calculator
Marketing Campaign ROAS &amp; Attribution Calculator
Excel model comparing 5 multi-touch attribution methods (first-touch, last-touch, linear, time-decay, position-based) to show how last-touch reporting can misstate channel ROAS plus a live budget-reallocation simulator for testing paths to a target ROAS uplift. Built with ~880 native formulas, no macros.
